# 📊 Data Analyst Presentation: Developer Survey Skills Analysis

## Overview

This repository contains a data analysis presentation focused on identifying the most in-demand developer skills, technology trends, and professional demographics based on the **Stack Overflow Developer Survey 2019**. The analysis was performed as a data project to guide decisions in hiring, training, and product roadmaps.

The project involved an end-to-end process from data collection and wrangling to visualization and drawing actionable insights.

## Project Details

* **Author:** Juan Mamani-Rojas
* **Date:** October 11, 2025
* **Source Data:** Stack Overflow Developer Survey 2019
* **Affiliation:** Skills Network (IBM)

## 🛠 Methodology and Tools

The analysis followed a structured methodology:

1.  **Data Collection:** Survey data was collected, explored, and content was extracted using **Web Scraping** and **APIs** (specifically the Request library).
2.  **Data Wrangling:** This involved exploratory data analysis, analyzing data distribution, handling outliers, and determining correlations.
3.  **Data Visualization:** Data was visualized to highlight distribution, relationships, composition, and comparisons.

### Tools Used

* **Data Preparation & Wrangling:** Python + Jupyter
* **Dashboards & Visuals:** IBM Cognos Analytics and Google Looker (Looker Studio)

## 🎯 Key Findings & Insights

The analysis scope covered Programming languages, databases, web frameworks, and cloud platforms.

### Current Technology Trends

* **Top Languages (Used):** JavaScript, SQL, HTML/CSS, TypeScript, and Python.
* **Top Databases (Used):** PostgreSQL (leader with 11,514 respondents), MySQL, and SQLite.
* **Top Cloud Platform (Used):** AWS (nearly 2,500 responses).

### Future Technology Trends (Desired Next Year)

* **Future Languages (Desired):** Python, JavaScript, and SQL are the most popular programming languages respondents anticipate next year.
* **Future Databases (Desired):** PostgreSQL maintains its leadership. Oracle is declining and is being replaced by emerging alternatives like Supabase.
* **Future Cloud Platform (Desired):** AWS is the most famous platform, with Microsoft Azure remaining strong at 2nd.

### Demographics

* **Dominant Age Group:** 25–34 years (~8,000 respondents).
* **Education Level:** Bachelor's degrees (~8,500) followed by Master’s degrees (~5,000).
* **Top Countries:** United States (~3,500 responses) followed by Germany (~1,500).

## 💡 Implications for Strategy

* **Technology Investment:** Companies should continue investing heavily in **Python** and **JavaScript**. PostgreSQL investment should be kept, and for SQL Server, maintenance is suggested while looking for alternatives for backup. **C# + SQL** combination should be considered to stay strong in the market.
* **Talent Strategy:** Recruitment and training efforts should be applied to the **age 25–34 group** with **Bachelor’s degrees**.
* **Location Strategy:** Companies should consider setting up location(s) in the **USA and Germany**.
* **Overall Market Shift:** The IT industry is increasingly shifting toward an **open-source, cloud-first ecosystem**.
